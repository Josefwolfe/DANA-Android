# درگاه اختیاری هوش مصنوعی دانا

این پوشه یک سرور واقعی، کوچک و بدون وابستگی غیرضروری پایتون دارد. **برای استفاده روی گوشی، این سرویس را روی سرور خودتان راه‌اندازی کنید.** کلید ارائه‌دهنده مدل هرگز نباید در اپ اندروید یا GitHub قرار بگیرد. سرویس بدون تنظیم رمز محرمانه قوی اصلاً شروع نمی‌شود.

## شروع روی سرور خودتان

```bash
export OPENAI_API_KEY='your-provider-api-key'
export DANA_LLM_MODEL='gpt-4o-mini'  # نام مدل مجاز حساب خود را جایگزین کنید
export DANA_GATEWAY_TOKEN='generate-a-very-long-random-secret-here'
python3 gateway/dana_gateway.py
```

در حالت پیش‌فرض سرور تنها روی `127.0.0.1:8080` گوش می‌دهد. **آن را مستقیم و بدون TLS روی اینترنت باز نکنید.** با Nginx یا Caddy یک دامنه HTTPS و Reverse Proxy برای پورت محلی تنظیم کنید. نمونه Caddyfile در همین پوشه موجود است. DNS و گواهی معتبر HTTPS باید روی سرور شما فعال شوند.

آدرس مثال در اپ: `https://dana.example.com/dana/intent`؛ در تنظیمات AI همان `DANA_GATEWAY_TOKEN` را به عنوان «رمز دسترسی سرور» وارد کنید. اپ رمز را با Android Keystore محافظت می‌کند. سپس برای استفاده اختیاری اجازه ارسال متن فرمان‌های ناشناخته را فعال کنید. نمونه سرور هیچ تاریخچه‌ای ذخیره نمی‌کند؛ سیاست داده‌های ارائه‌دهنده مدل را جداگانه بررسی کنید.

آزمون مستقل (۱۰ مورد شامل ۴ تست HTTP محلی): `python3 -m unittest discover -s gateway/tests -v`

این سرویس از API استاندارد Chat Completions با JSON Mode برای **طبقه‌بندی فرمان‌ها** استفاده می‌کند و هیچ عملی روی گوشی انجام نمی‌دهد. حتی خروجی مدل پس از اعتبارسنجی در گوشی برای تماس و پیش‌نویس پیام به تأیید کاربر نیاز دارد. اطلاعات حساس مانند مخاطبین، سابقه و حافظه داخل درخواست وارد نمی‌شوند؛ اما متن گفته‌شده خود می‌تواند اطلاعات شخصی داشته باشد. برای مقیاس عمومی، پایش سوءاستفاده، rate-limit دقیق‌تر و بازبینی امنیتی ضروری است.


## v1.6: فرمان‌های گسترده‌تر و سؤال‌های عمومی

در این نسخه سرور می‌تواند فرمان‌های موسیقی، اتصال‌ها، تایمر، آلارم و سؤال‌های عمومی کوتاه را نیز دسته‌بندی کند. کلید API باید فقط روی سرور بماند. فرمان‌های نامعتبر و درخواست کنترل نامحدود گوشی رد می‌شوند. مدل ممکن است در پاسخ‌های عمومی اشتباه کند.
