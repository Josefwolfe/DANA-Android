# DANA Android v1.3 RC4 — Build-ready source

**وضعیت واقعی:** آزمون‌های مستقل قابل اجرای این محیط انجام شده‌اند؛ Android SDK و Gradle محلی در این محیط موجود نیستند، پس فایل APK هنوز ساخته و روی گوشی واقعی تست نشده است. نام `Build-ready` به معنی «آماده تلاش برای ساخت در Android Studio یا CI» است، نه تضمین عدم خطای کامپایل.

**تغییرات نسبت به RC1:** تأیید جداگانه برای ذخیره نام مستعار مخاطب؛ مدیریت خطای اتصال اولیه سرور AI بدون قفل شدن حالت درخواست؛ نمایش خطای روشن شدن سرویس شنود در اندرویدهای جدید؛ دریافت خودکار و تأیید SHA-256 فایل رسمی Gradle Wrapper در اسکریپت‌های ساخت.

**مسیر ساخت توصیه‌شده:** Android Studio دارای Android SDK API 35 و JDK 17، باز کردن پوشه پروژه، اجرای `scripts/build_apk.bat` در ویندوز یا `bash scripts/build_apk.sh` در لینوکس/مک. اتصال اینترنت در اولین Build برای Gradle، وابستگی Vosk و دانلود Wrapper لازم است. فایل APK در `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود، به شرط موفقیت Gradle.

**ساخت ابری:** اگر مایل نیستی Android Studio نصب کنی، فایل‌های داخل پوشه را در ریشه یک مخزن GitHub بگذار و Action با نام `Build DANA installable APK` را اجرا کن. بدون مخزن GitHub خودکار اجرا نمی‌شود. اگر build شکست خورد، لاگ Actions را برای رفع مشکل لازم داری.

**محدودیت‌های محصول:** بیدارباش آفلاین با Vosk آزمایشی و اختیاری است، نیاز به نصب جداگانه مدل کوچک فارسی دارد و مصرف باتری و عملکرد صفحه‌خاموش تأیید نشده است. AI آنلاین تنها با نشانی HTTPS سرور شخصی و فعال کردن اختیاری کار می‌کند. هیچ کلید سرویس AI در APK ذخیره نمی‌شود. صدای زن طبیعی تضمین نشده و به صدای فارسی نصب‌شده در دستگاه بستگی دارد. تماس مستقیم و پیامک تأیید کاربر می‌خواهند؛ پیامک فقط پیش‌نویس باز می‌کند.

جزییات: `docs/FINAL_APK_STEPS_FA.md`، `docs/DEVICE_TEST_CHECKLIST_FA.md` و `docs/BUILD_STATUS_FA.md`.

# DANA Android 1.3 RC4 — بسته کامل سورس قابل ساخت

**این تحویل سورس کامل نسخه آزمایشی اندروید است، نه APK کامپایل‌شده و نه محصول آزمایش‌شده روی گوشی.** در محیط تهیه، اینترنت دریافت SDK و Android SDK/Gradle وجود نداشت. ساخت APK و آزمون واقعی باتری/میکروفون باید در Android Studio یا GitHub Actions انجام شوند.

## امکاناتی که کدنویسی شده‌اند

- رابط فارسی راست‌چین، اسم کاربر در اولین ورود، حافظه محلی و انتخاب صدای فارسی نصب‌شده؛ **صدای زن طبیعی تضمین‌شده نیست** و به بسته TTS موجود روی گوشی بستگی دارد.
- تشخیص گفتار فارسی از سرویس Android، فرمان متنی برای آزمایش بدون میکروفون، تحلیل آفلاین الگوهای رایج فارسی و پاسخ صوتی. در اولین دسترسی، درباره احتمال پردازش گفتار توسط ارائه‌دهنده سیستم توضیح داده می‌شود؛ در حالت خصوصی فقط مسیر تشخیص روی دستگاه مجاز است.
- جستجوی مخاطبین و اسم مستعار، درخواست تأیید پیش از تماس؛ تهیه پیش‌نویس پیامک و ارسال نهایی توسط خود کاربر در برنامه پیامک.
- باز کردن اپ‌های قابل‌شناسایی، دوربین، مخاطبین و تقویم؛ چراغ قوه، صدا، موزیک، باتری و ساعت؛ باز کردن تنظیمات وای‌فای/بلوتوث در صورت محدودیت اندروید.
- یادداشت، فهرست کارها، آلارم/تایمر از برنامه ساعت و یادآوری داخلی با اعلان و بازسازی بعد از ری‌استارت. یادآوری‌های داخلی به‌خاطر محدودیت Doze ممکن است با تأخیر ظاهر شوند.
- حالت خصوصی، خاموش کردن یادگیری، پاک کردن داده‌ها، خلاصه اعلان‌ها با مجوز اختیاری، میانبر اعلان، گزارش آزمون.
- بیدارباش **آفلاین آزمایشی** با Vosk پس از وارد کردن دستی مدل فارسی و فعال‌سازی از داخل اپ باز. با صفحه خاموش ممکن است روی برخی گوشی‌ها ادامه دهد؛ هیچ تضمین پایداری همگانی یا مصرف بسیار پایین وجود ندارد. بیدارباش در Battery Saver یا زیر ۱۵٪ شارژ (بدون اتصال شارژر) متوقف می‌شود و هنگام تماس میکروفون را آزاد می‌کند. سرویس از بوت به‌طور خودکار فعال نمی‌شود.
- اتصال AI اختیاری برای فرمان‌های محلی ناشناخته از طریق HTTPS. **سرور واسط واقعی در پوشه `gateway/` آمده است**؛ برای استفاده به سرور HTTPS، کلید API و رمز درگاه مخصوص خودتان نیاز دارید. رمز در گوشی با Android Keystore محافظت می‌شود. خروجی مدل به فهرست ایمن محدود است و تماس/پیام همچنان تأیید می‌خواهند.

## تبدیل به APK روی سیستم خودتان

۱. فایل ZIP را استخراج کنید و پوشه `DANA-Android` که `settings.gradle.kts` داخل آن است در **Android Studio** باز کنید.

۲. نصب/تأیید JDK 17، Android SDK Platform 35، Build Tools 35.0.0 و اینترنت اولیه برای Gradle 8.9 و کتابخانه Vosk 0.3.47. در Android Studio از **Settings → Android SDK** نصب کنید. مسیر دستی دریافت و اعتبارسنجی Gradle Wrapper داخل `scripts/fetch_wrapper.py` است.

۳. روی ویندوز: `scripts\build_apk.bat`؛ روی لینوکس/مک: `bash scripts/build_apk.sh`. این اسکریپت بررسی ایستا، آزمون Python، آزمون‌های Gradle/JUnit و `lintDebug` را اجرا می‌کند و در صورت موفقیت APK را تولید می‌کند.

۴. مسیر فایل نصب آزمایشی: `app/build/outputs/apk/debug/app-debug.apk`.

۵. روش جایگزین بدون Android Studio: پوشه را در یک مخزن شخصی GitHub قرار بدهید، **Actions → Build DANA installable APK → Run workflow**. پس از موفقیت Build، APK را از Artifacts با نام `DANA-v1.3.0-rc4-debug-APK` بگیرید. این فرایند در محیط فعلی اجرا نشده است.
