# وضعیت واقعی پیاده‌سازی — DANA Android 1.3 RC4

**نسخه این بسته سورس Release Candidate آزمایشی است، نه APK تأییدشده یا محصول آماده انتشار عمومی.** برای آخرین نتیجه آزمون‌ها به `BUILD_STATUS_FA.md` مراجعه کنید.

## در سورس پیاده‌سازی شده

- رابط فارسی، نام و تنظیمات کاربر، تشخیص گفتار فارسی وابسته به سرویس گوشی، انتخاب صدای TTS فارسی موجود، ورودی متنی، موتور فرمان‌های رایج و رد فرمان‌های منفی.
- تماس با مخاطب پس از انتخاب و تأیید؛ پیامک **فقط پیش‌نویس** در برنامه SMS گوشی؛ باز کردن برنامه‌های قابل‌شناسایی و تنظیمات، چراغ قوه، کنترل صدا و پخش موسیقی.
- یادآوری‌های غیر‌دقیق داخلی، یادداشت، کارها، آلارم و تایمر از طریق برنامه ساعت؛ میانبر اعلان و گزارش خطای اختیاری.
- حالت خصوصی، خاموش کردن یادگیری، حذف حافظه، مدیریت اختیاری اعلان‌ها، محدودسازی عملیات روی صفحه قفل.
- **بیدارباش آفلاین آزمایشی:** Vosk فارسی با مدل جداگانه؛ شروع فقط از برنامه باز و با اجازه، اعلان قابل توقف، توقف هنگام تماس/Battery Saver/باتری کمتر از ۱۵٪ بدون شارژ. پایداری با صفحه خاموش و مصرف آن اثبات نشده است.
- **AI آنلاین اختیاری:** کلاینت HTTPS، رمز مستقل ذخیره‌شده با Android Keystore و سرور نمونه پایتون با کلید مدل در سمت سرور. فقط طبقه‌بندی مجموعه فرمان مجاز، نه کنترل نامحدود اندروید؛ سرور باید جداگانه با HTTPS راه‌اندازی شود.
- سورس، سناریوهای آزمایش مستقل، آزمون HTTP سرور، GitHub Actions برای APK آزمایشی و مسیر Release امضاشده با Keystore شخصی.

## انجام نشده / نیازمند آزمون خارج این محیط

- ساخت موفق Android Gradle یا APK نصب‌شده؛ Android SDK/Gradle و دسترسی دانلود در محیط تولید وجود نداشت.
- راه‌اندازی واقعی API مدل و بررسی مدل‌ خروجی، واردکردن مدل زبان Vosk معتبر، آزمون روی گوشی و سنجش مصرف باتری و تداخل برنامه‌های دیگر.
- تضمین فعالیت همیشه‌فعال روی تمام گوشی‌ها و با صفحه قفل؛ اندروید و سازنده گوشی محدودیت دارند.
- صدای زن Neural مستقل و تضمین‌شده؛ فعلاً به صداهای TTS نصب‌شده گوشی وابسته است.
- احراز هویت دقیق صاحب صدا، تشخیص احساس، کنترل نامحدود همه امکانات گوشی، ارسال خودکار SMS و رمزگذاری اختصاصی کل حافظه محلی. ادعای کارکرد این موارد نادرست خواهد بود.

**محدوده انتشار فعلی:** فقط تست خصوصی گوشی اندروید. بعد از Build، چک‌لیست `DEVICE_TEST_CHECKLIST_FA.md` را روی گوشی واقعی انجام دهید.
