# ساخت APK دانا از این پروژه — نسخه سورس 1.3 RC4

## روش آسان: کامپایل خودکار در GitHub

1. ZIP پروژه را استخراج کنید. **محتویات پوشه `DANA-Android` را در ریشه مخزن** GitHub بگذارید؛ `settings.gradle.kts` باید مستقیم در صفحه اول مخزن باشد.
2. به بخش **Actions** بروید و گردش‌کار **Build DANA installable APK** را باز کنید.
3. **Run workflow** را انتخاب کنید یا محتوا را به شاخه `main` یا `master` Push کنید.
4. در اجرای موفق، خروجی `DANA-v1.3.0-rc4-debug-APK` را از **Artifacts** دانلود کنید.
5. فایل `app-debug.apk` را به گوشی منتقل کنید، نصب از منبع مربوط را در صورت نیاز تأیید کنید و امکانات را آزمایش کنید.
6. اگر ساخت خطا داشت، گزارش مرحله `Compile, test, lint and build installable debug APK` را مطالعه کنید. این سورس هنوز با Android SDK کامپایل نشده و نتیجه این مرحله از قبل قطعی نیست.

گردش‌کار از JDK 17، Android API 35، Build-tools 35.0.0، Android Gradle Plugin 8.7.3، Kotlin 1.9.25 و Gradle 8.9 استفاده می‌کند. ZIP از مخزن شخصی شما استفاده می‌کند و نیازی به انتشار سورس به یک سرور ناشناس ندارد.

## روش دوم: Android Studio (ویندوز)

1. آخرین Android Studio سازگار با AGP 8.7.3، JDK 17 و Android SDK Platform 35 را نصب کنید.
2. ZIP را استخراج و در صورت نیاز ابتدا `python3 scripts/doctor.py` را برای نمایش پیش‌نیازها اجرا کنید. از منوی **Open** مسیر پوشه دارای `settings.gradle.kts` را انتخاب کنید.
3. از **Terminal** در همان پوشه `gradlew.bat --version` را اجرا کنید. اینترنت برای اولین اجرای Bootstrap لازم است؛ نسخه رسمی Gradle wrapper JAR دانلود و در برابر SHA-256 رسمی آن بررسی می‌شود. نسخه کامل Gradle 8.9 هم با SHA-256 موجود در `gradle-wrapper.properties` بررسی می‌شود.
4. **Sync Project with Gradle Files** را اجرا کنید؛ اگر Android Studio محل SDK را پرسید، مسیر نصب SDK را انتخاب کنید.
5. `scripts\build_apk.bat` را اجرا کنید یا از منوی **Build → Build APK(s)** استفاده کنید.
6. خروجی: `app\build\outputs\apk\debug\app-debug.apk`.

در لینوکس/مک: `./gradlew --version` و سپس `./scripts/build_apk.sh`.

## اگر اینترنت برای Gradle روی کامپیوتر در دسترس نیست

از روش GitHub Actions استفاده کنید؛ آن نیز برای دانلود وابستگی‌ها و ساخت به دسترسی شبکه نیاز دارد. اگر مجبور به Build کاملاً آفلاین هستید، باید Gradle 8.9، AGP/Kotlin و کل Android SDK از قبل روی دستگاه و در Cache نصب باشند. درون ZIP، فایل‌های بزرگ SDK یا بسته‌های JAR با منبع نامشخص قرار داده نشده‌اند.

## انتشار عمومی در آینده

این خروجی `debug.apk` برای تست خصوصی است. برای Release امضاشده از `docs/RELEASE_BUILD_FA.md` استفاده کنید. Keystore اختصاصی خودتان را خارج از Git نگه دارید و رمز آن را داخل سورس قرار ندهید. سپس مجوزها، سیاست حریم خصوصی، مدل هوش و پردازش صدا را برای بازار موردنظر بررسی کنید.

## نکات تست گوشی

اول نام خود را ذخیره کنید. هنگام زدن دکمه صحبت، مجوز میکروفون را بدهید. صدای فارسی باید در بخش Text-to-Speech تنظیمات گوشی نصب شده باشد؛ برنامه بخش انتخاب و پیش‌نمایش صدای فارسی دارد. برای تماس، دسترسی مخاطبین و تماس هنگام اولین نیاز درخواست می‌شوند؛ برای پیامک، اپ پیش‌فرض پیامک باز می‌شود و ارسال نهایی با تأیید شماست.

اگر موتور گفتار فارسی خطا داد، از **فرمان متنی** داخل برنامه استفاده کنید تا عملکرد موتور فرمان را جدا از میکروفون آزمایش کنید. برای Wake Word آزمایشی، مدل Vosk باید جداگانه نصب شود؛ این قابلیت هنوز نیازمند تست روی گوشی است.


**موجود در نسخه RC3:** وابستگی Vosk از Maven Central هنگام اولین Build دریافت می‌شود. پس از نصب APK، برای بیدارباش آفلاین، مدل کوچک فارسی را جداگانه در داخل اپ نصب کنید. مراجعه: `WAKE_WORD_SETUP_FA.md`.


## درگاه هوش مصنوعی واقعی (اختیاری)

سورس سرور در `gateway/dana_gateway.py` و دستور نصب/امنیت در `gateway/README_FA.md` موجود است. راه‌اندازی سرور، داشتن کلید API و یک دامنه HTTPS با رمز مستقل ضروری است. **این سرور برای کامپایل APK لازم نیست**؛ فرمان‌های پرکاربرد بدون این سرویس اجرا می‌شوند.
