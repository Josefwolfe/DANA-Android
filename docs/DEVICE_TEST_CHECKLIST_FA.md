# چک‌لیست پذیرش نسخه نصب‌شدنی دانا

پس از Build موفق و نصب `app-debug.apk` روی گوشی، همه موارد را روی **همان مدل گوشی هدف** انجام دهید. داده تست واقعی را خودتان بنویسید، نه عدد حدسی.

## روز ۱: نصب و شروع

- [ ] APK بدون Crash نصب و باز می‌شود.
- [ ] دانا در اولین اجرا نام را می‌پرسد؛ پس از بستن کامل و بازکردن مجدد، نام را نگه می‌دارد.
- [ ] در حالت متنی، فرمان‌های ساعت، باتری، چراغ و دوربین درست کار می‌کنند.
- [ ] مجوزهای غیرضروری قبل از اولین استفاده درخواست نمی‌شوند.

## روز ۲: ارتباطات

- [ ] مخاطب یکتا، نام مشابه و مخاطب بدون شماره درست مدیریت می‌شوند.
- [ ] هیچ تماس بدون تأیید صاحب گوشی شروع نمی‌شود.
- [ ] پیامک فقط به‌صورت پیش‌نویس باز می‌شود؛ متن و گیرنده قبل از آن تأیید می‌شوند.

## روز ۳: گفتار

- [ ] تشخیص فارسی در اتاق آرام، مکان شلوغ و هنگام قطع اینترنت آزمایش شود.
- [ ] صدای فارسی نصب‌شده قابل انتخاب است؛ اگر صدای زن مناسب موجود نیست، مشکل ثبت شود.
- [ ] هنگام تماس تلفنی، میکروفون دانا آزاد می‌شود.

## روز ۴: بیدارباش (اختیاری)

- [ ] مدل کوچک فارسی Vosk از ZIP رسمی نصب می‌شود و آزمایش آغاز از داخل اپ باز انجام می‌شود.
- [ ] فرمان حساس روی صفحه قفل اجرا نمی‌شود و درخواست بازکردن قفل دارد.
- [ ] صفحه خاموش: چند نوبت فعال‌سازی و خطای فعال شدن اشتباه ثبت شود.
- [ ] باتری کمتر از ۱۵٪ و Battery Saver سرویس را متوقف می‌کند.
- [ ] از نوار اعلان می‌توان شنود را متوقف کرد.
- [ ] پس از راه‌اندازی مجدد گوشی، سرویس میکروفون خودکار شروع نمی‌شود.

## روز ۵: حافظه و یادآوری

- [ ] یادداشت و فهرست کارها بعد از بستن اپ باقی می‌مانند.
- [ ] یادآوری ۱۵ دقیقه‌ای و یادآوری فردا کار می‌کنند (تأخیر Doze ثبت شود).
- [ ] حالت خصوصی ثبت آمار و یادگیری جدید را قطع می‌کند؛ پاک کردن حافظه تمام داده‌های محلی را حذف می‌کند.

## روز ۶: باتری و پایداری

- [ ] شارژ ابتدای آزمایش، زمان شروع، نوع شبکه و روشن/خاموش بودن صفحه ثبت شود.
- [ ] مصرف یک ساعت آماده‌باش **با بیدارباش خاموش** ثبت شود.
- [ ] مصرف یک ساعت با بیدارباش Vosk روشن (در صورت امکان) ثبت و مقایسه شود.
- [ ] دستگاه داغ نمی‌شود؛ موزیک، تماس، دوربین و اپ‌های دیگر رفتار طبیعی دارند.

## روز ۷: پذیرش یا اصلاح

- [ ] فرمان‌های شکست‌خورده با متن دقیق و نوع خطا ثبت شوند.
- [ ] اگر Crash/تأخیر شدید/مصرف غیرقابل‌قبول وجود داشت، آن مورد باید قبل از انتشار اصلاح شود.
- [ ] Build Release با کلید امضای اختصاصی، مرور مجوزها و سیاست حریم خصوصی جداگانه انجام شود.

برای تست خودکار نصب:

```bash
bash scripts/device_smoke.sh app/build/outputs/apk/debug/app-debug.apk
```

این اسکریپت فقط نصب و اجرای Activity را بررسی می‌کند و جایگزین تست کارکرد صوتی نیست.
