# تحویل نهایی سورس قابل ساخت DANA v1.3 RC4

این بسته برای تبدیل خارج از این محیط به APK آماده شده است.

## سریع‌ترین مسیر

1. پوشه `DANA-Android` را در Android Studio باز کن.
2. JDK 17+، Android SDK Platform 35 و Build Tools 35.0.0 را نصب کن.
3. اینترنت را در اولین Build روشن بگذار تا Gradle و وابستگی‌ها دریافت شوند.
4. برای APK آزمایشی `scripts/build_apk.bat` (ویندوز) یا `./scripts/build_apk.sh` را اجرا کن.
5. خروجی Debug در `app/build/outputs/apk/debug/app-debug.apk` است.
6. برای Release امضاشده، `docs/RELEASE_BUILD_FA.md` را انجام بده.

## چه چیزهایی عمداً داخل ZIP نیست

- `gradle-wrapper.jar`: در اولین Build از منبع رسمی Gradle دانلود و SHA-256 آن تأیید می‌شود.
- مدل فارسی Vosk: به دلیل حجم زیاد و لایسنس/نسخه مستقل، از داخل برنامه توسط کاربر از فایل ZIP نصب می‌شود.
- API key سرویس AI: کلید ارائه‌دهنده فقط روی Gateway سرور قرار می‌گیرد، نه داخل APK.
- Keystore نسخه Release: باید متعلق به صاحب برنامه باشد و داخل سورس ذخیره نشود.

## وضعیت قابلیت‌های حساس

Wake word با میکروفون Foreground Service پیاده‌سازی آزمایشی شده و باید روی گوشی واقعی از نظر باتری، OEM background killing، تماس تلفنی و خاموش بودن صفحه تست شود. ارسال SMS مستقیم انجام نمی‌شود؛ دانا پیش‌نویس پیام را باز می‌کند. تماس مستقیم فقط پس از تأیید و Permission انجام می‌شود و در صورت خطا Dialer باز می‌شود.
