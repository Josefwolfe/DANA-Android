# درگاه واقعی AI دانا (اختیاری)

سرور نمونه قابل اجرا در [`../gateway/dana_gateway.py`](../gateway/dana_gateway.py) قرار دارد. برای آموزش و راه‌اندازی با کلید سمت سرور، HTTPS و رمز مستقل به [`../gateway/README_FA.md`](../gateway/README_FA.md) مراجعه کنید. برنامه کلید شرکت ارائه‌دهنده مدل را نگه نمی‌دارد؛ فقط رمز درگاه اختصاصی با Android Keystore ذخیره می‌شود.

# درگاه اختیاری هوش مصنوعی دانا

هسته اصلی دانا همچنان بدون اینترنت بر اساس موتور فرمان‌های فارسی کار می‌کند. اتصال AI **پیش‌فرض خاموش** است و فقط برای دستورهایی که موتور محلی آن‌ها را نمی‌فهمد استفاده می‌شود. حالت خصوصی این اتصال را غیرفعال می‌کند.

## فعال‌سازی

در صفحه اصلی روی «تنظیم هوش مصنوعی آنلاین (اختیاری)» بزنید، URL سرور HTTPS مورد اعتماد خود را وارد کنید و جداگانه اجازه ارسال متن همان فرمان را صادر کنید. تغییر URL این اجازه را دوباره باطل می‌کند. برنامه هیچ کلید اختصاصی ارائه‌دهنده AI را در APK قرار نمی‌دهد. کلیدها فقط باید **روی سرور واسط** نگهداری شوند.

## قرارداد درخواست

`POST https://your-server.example/dana/intent`

درخواست JSON:

```json
{"language":"fa","text":"رضا رو بگیر","actions":"TIME,BATTERY,OPEN_CAMERA,OPEN_CONTACTS,OPEN_APP,CALL,SMS_DRAFT,FLASH_ON,FLASH_OFF,VOLUME_UP,VOLUME_DOWN"}
```

پاسخ مجاز JSON:

```json
{"action":"CALL","target":"رضا"}
```

برای پیش‌نویس پیام:

```json
{"action":"SMS_DRAFT","target":"محمد","message":"امروز دیر می‌رسم"}
```

اگر دستور مبهم بود:

```json
{"needs_clarification":true}
```

## قرارداد امنیتی

- پاسخ AI **دستور سیستم‌عامل نیست**: برنامه آن را به فهرست مجاز محدود و فیلدها را اعتبارسنجی می‌کند.
- AI نمی‌تواند درخواست حذف فایل، خرید، دسترسی پنهانی یا گرفتن مجوز را با افزودن JSON جدید به گوشی تحمیل کند.
- تماس‌ها پس از بررسی مخاطب با تأیید کاربر شروع می‌شوند؛ پیامک صرفاً پیش‌نویس است و ارسال نهایی به اپ پیامک واگذار می‌شود.
- فقط متن یک درخواست نامفهوم ارسال می‌شود، نه تاریخچه مکالمه، لیست مخاطبین یا فایل‌ها؛ با این حال متن گفتار ممکن است شخصی باشد. سرور شما مسئول نگهداری و حفاظت از آن است.
- دریافت پاسخ حداکثر چند ثانیه فرصت دارد؛ قطع اینترنت/سرور هرگز باعث اجرای حدسی دستور نمی‌شود.

**نکته:** این پروژه درگاه هوش مصنوعی و کنترل خروجی آن را کدنویسی می‌کند. مدل LLM همراه بسته نیست؛ اما **کد یک سرور عملی قابل راه‌اندازی با Python در پوشه `gateway/` ارائه شده است**؛ برای درک بسیار آزادتر فارسی باید سرور HTTPS سازگار با این قرارداد راه‌اندازی شود.
