# وضعیت مهندسی — DANA Android 1.3 RC4

تاریخ بسته‌بندی: ۲۰۲۶/۱۰/۰۳

| بخش | وضعیت |
|---|---|
| ساختار پروژه Kotlin / XML | فایل‌ها و ارجاع‌ها به‌صورت ایستا بررسی شده‌اند |
| Kotlin CLI آزمون موتور فرمان و یادآوری و ایمنی | ۱۴۴ از ۱۴۴ موفق |
| سرور نمونه AI (Python) | پیاده‌سازی و ۱۰ آزمون موفق (۶ یونیت + ۴ HTTP محلی)؛ به کلید و استقرار HTTPS نیاز دارد |
| اسکریپت ساخت و GitHub Actions | آماده اجرا، **هنوز در محیط دارای Android SDK اجرا نشده** |
| Gradle build / APK | نیازمند محیط دارای Android SDK، Maven و اینترنت اولیه |
| تماس/SMS و نرم‌افزارهای جانبی | مسیر کد موجود؛ باید روی گوشی با مجوز و مخاطب آزمایش شوند |
| بیدارباش صفحه خاموش | آزمایشی؛ وابسته به مدل و سیاست سازنده گوشی؛ کیفیت/مصرف تأیید نشده |
| TTS زن فارسی | انتخاب از صداهای نصب‌شده؛ صدای Neural مستقل در بسته موجود نیست |
| نشر عمومی | انجام نشده؛ فعلاً APK دیباگ مناسب آزمایش خصوصی است |

آزمون‌های موفق نشان‌دهنده کیفیت همه دستگاه‌ها یا زمان واقعی پاسخ نیستند. عددهای دقت ۹۶٪ و مصرف پایین از نسخه‌های مفهومی قبلی **داده آزمایشگاهی نیستند**.

## اصلاحات RC3
- ذخیره نام مستعار مخاطب تنها بعد از «بله» جداگانه؛ حالت خصوصی یا یادگیری غیرفعال ذخیره نمی‌کنند.
- خطای اولیه HTTPS باعث گیر کردن وضعیت درخواست AI نمی‌شود.
- ممنوعیت راه‌اندازی سرویس شنود توسط اندروید به کاربر اعلام می‌شود.
- اسکریپت‌های Build فایل Gradle Wrapper را از منبع رسمی دریافت و SHA-256 آن را اعتبارسنجی می‌کنند.
- مسیر جداگانه APK Release امضاشده با متغیرهای محیطی/Secrets و بررسی `apksigner` اضافه شد.
- Network Security Config صراحتاً Cleartext را ممنوع می‌کند و Preflight پیش‌نیازهای Build را بررسی می‌کند.
- آزمون‌های مستقل: ۱۴۴ سناریوی Kotlin و ۱۰ آزمون Python. هنوز APK در محیط دارای SDK کامپایل نشده است.
